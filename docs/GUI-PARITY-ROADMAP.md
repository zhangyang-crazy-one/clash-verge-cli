# GUI Parity Roadmap

Phased plan to reach Clash Verge Rev GUI feature parity in `clash-verge-cli`.
Tray, global hotkeys, and lightweight window mode are explicitly out of scope.

## Done / in progress

- **Phase 1 — Subscriptions**: remote import/update (TUI `i`/`u` + `profile import|update|list`), Clash YAML validation, chain fragments, SSRF-safe fetch, mihomo **v1.19.29** auto-install on start.

## Upcoming

- **Phase 2 — Profiles CRUD + enhance**: delete/rename/local import, full enhance chain (including script), auto-update timer.
- **Phase 3 — System integration**: system proxy, clash mode, TUN, service CLI.
- **Phase 4 — Proxies / Rules / observability**: providers, real rules API, close-all connections, log levels.
- **Phase 5 — Settings / DNS / runtime**: editable ports and verge options, DNS/runtime YAML via `$EDITOR`.
- **Phase 6 — Unlock / media tests** (optional).
- **Phase 7 — Backup / WebDAV** (later).
